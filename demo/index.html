Web Component

只填一个 UID，展示你的 B 站名片。

原生 Custom Element，带 Shadow DOM 样式隔离。普通 HTML、博客、Vue、React、 Astro 等环境都能使用。

最小用法

<script type="module"
  src="https://bili-info-card.vercel.app/bilibili-user-card.js">
</script>

<bilibili-user-card
  uid="7900967">
</bilibili-user-card>

卡片每次打开页面都会请求 API；服务端缓存十分钟，减少 B 站风控与无意义的重复请求。
